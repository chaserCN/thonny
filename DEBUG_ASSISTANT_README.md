# Debug AI Assistant для Thonny

## Что это?

Новый плагин для Thonny, который добавляет AI-ассистента прямо в отладчик! 🤖

## Функции

### 🐛 **Explain current step** - Объясняет текущий шаг
- Что делает текущая строка кода
- Какие значения у переменных сейчас
- Почему выполнение остановилось здесь

### 🔮 **What happens next?** - Предсказывает следующий шаг
- Что произойдет при выполнении следующего шага
- Какая строка будет выполнена
- Как изменятся переменные

### 📊 **Show variables** - Показывает переменные
- Объясняет все текущие переменные
- Показывает их значения
- Объясняет что они означают в контексте программы

## Как использовать?

### 1. Настройка API ключа

Перед первым использованием нужно настроить OpenAI API key:
1. Получите API ключ на https://platform.openai.com/api-keys
2. Запустите Thonny
3. Попробуйте использовать Debug AI - появится диалог для ввода ключа
4. Вставьте ваш API ключ

### 2. Запуск отладки

```bash
cd /Users/yarohort/Projects/thonny
source venv/bin/activate
python -m thonny
```

### 3. Использование

1. **Откройте любой Python файл** (например, ваш код с циклом)

2. **Запустите отладку**: 
   - Run → Debug current script (faster) - или **Shift+F5**
   - Или Run → Debug current script (nicer) - или **Ctrl+F5**

3. **Откройте Chat панель**:
   - View → Chat (или найдите вкладку Chat)

4. **Во время отладки** в панели Chat появятся специальные кнопки:
   - 🐛 Explain current step
   - 🔮 What happens next?
   - 📊 Show variables

5. **Кликните на любую кнопку** - AI объяснит что происходит!

6. **Или просто спросите**:
   - "Почему i равно 2?"
   - "Что делает эта строка?"
   - "Объясни цикл"

## Пример использования

```python
n=int(input("n="))
mas=list(map(int,input().split()))
mas1=[mas[0]]

for i in range(1,n):
    mas1.append(mas[i]-mas[i-1])  # ← Остановились здесь

print(*mas1)
```

Когда вы остановитесь на строке с циклом:
- **Кликните "🐛 Explain current step"** → AI объяснит что делает `mas[i]-mas[i-1]`, покажет текущие значения `i`, `mas[i]`, `mas[i-1]`
- **Кликните "🔮 What happens next?"** → AI предскажет как изменится `mas1` после выполнения

## Архитектура

```
ChatView (панель чата)
    ↓
DebugAIAssistant (наследует OpenAIAssistant)
    ↓
get_debug_context() - получает контекст отладки
    ↓
- Текущая строка кода
- Все переменные (locals/globals)
- Стек вызовов
    ↓
OpenAI API (GPT-4o-mini)
    ↓
Объяснение для пользователя
```

## Технические детали

### Получение контекста отладки:
```python
debugger = get_current_debugger()
msg = debugger._last_progress_message
frame = msg.stack[-1]  # Текущий фрейм

# Доступно:
- frame.filename      # Имя файла
- frame.lineno        # Номер строки
- frame.code_name     # Имя функции
- frame.focus         # Текущая строка кода
- frame.locals        # Локальные переменные
- frame.globals       # Глобальные переменные
```

### Интеграция с OpenAI:
- Модель: `gpt-4o-mini`
- Streaming: Да (текст появляется постепенно)
- Контекст: Автоматически добавляется информация о текущем состоянии
